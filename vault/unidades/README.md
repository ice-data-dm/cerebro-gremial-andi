# Unidades de negocio

Una ficha por cada una de las cinco unidades de UNIANDI. Cada ficha es la
fuente de la verdad de: las marcas y el portafolio con precios sugeridos, cómo
le va a la unidad con cada cliente, y las reglas operativas que la unidad ya
aprendió (a veces pagando caro).

Si cambia un precio de lista, una marca o una condición, se actualiza aquí —
no en la cabeza de nadie.

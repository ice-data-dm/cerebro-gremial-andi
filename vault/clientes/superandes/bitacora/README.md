# Bitácora — SuperAndes

El diario de visitas y reuniones con el cliente: participantes, hechos y
necesidades expresadas, decisiones tomadas, compromisos de cada parte (con
dueño y fecha) y la próxima interacción acordada.

Las citas con compradores son martes y jueves — lo que un comprador le dice a
un KAM el martes, aquí lo lee el resto de la compañía el mismo día.

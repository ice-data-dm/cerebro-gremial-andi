# Promociones — SuperAndes

Una promoción por documento: mecánica, inversión, resultado contra línea base
(sell-in y sell-out) y — la parte más valiosa — el aprendizaje con su
recomendación: repetir, ajustar o detener.

En una gran superficie las lecciones cuestan millones: canibalización entre
referencias, inventario que no aguantó el pico, mecánicas que no movieron la
aguja. Registrar el aprendizaje evita que otra unidad pague la misma matrícula.

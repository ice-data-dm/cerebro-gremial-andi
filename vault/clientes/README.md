# Directorio de clientes

Una carpeta por cliente. Dentro de cada una: `00-ficha.md` (lo que todo KAM
debe saber antes de sentarse con el cliente), `contactos.md`, `incidentes/`,
`promociones/`, `bitacora/` y `pendientes.md`. Los clientes nuevos entran al
CRM con su ficha completa (canal, ciudad, contacto y condiciones) y aparecen
automáticamente en este directorio.
